How

  • All drives are read at the same time. Hard drives are read in path order, so the disk head does not jump around.
  • Name, size and photo details come first. Only files that can still be copies get a fingerprint, and a fingerprint starts with a small part of the file.
  • Photos match on camera and capture time from the header. No pixels are compared.
  • The catalog is kept. A rescan only opens folders that changed.

A tool that hashes every file in full has to read every byte: all {{facts.driveDataGb}}, not {{facts.contentReadGb}}.
